# Documentation Map

The generated wiki owns the architecture, specification, and procedure index. `README.md` remains the public usage guide; `skills/vstyle/` remains the agent usage workflow. [Quickstart](../quickstart.md) routes product and code questions; architecture pages explain runtime ownership; specifications preserve normative contracts; runbooks preserve procedures; this page records the migration boundary and document contracts. The former `docs/` tree has been removed after migration; the table below is the exact legacy-to-canonical mapping.

## Contracts

Each concept page uses OKF front matter. Normative pages label status and define exact names; runbooks state goal, inputs, dependencies, and verification; references state purpose and coverage. `index.md` files are reserved and generated by OpenWiki. Run queues, Claims sidecars, provenance, and update metadata are managed by OpenWiki. They are not manually maintained concept pages.

Current implementation owners include `engine.rs` for fix transactions, `workspace.rs` for discovery, `rules.rs` for dispatch, and `imports/` for import mechanisms and policies. Engine regressions live in `src/style/tests/`; integration targets share `tests/support/fixture.rs`. The benchmark entrypoints share `scripts/benchmark-common.bash`.

Source code and tests are authoritative. README and former docs are intent/routing evidence; if they disagree with implementation, document current source behavior and note the gap rather than preserving stale prose.

# Documentation Map

The generated wiki is the canonical documentation surface. [Quickstart](../quickstart.md) routes product and code questions; architecture pages explain runtime ownership; specifications preserve normative contracts; runbooks preserve procedures; this page records the migration boundary and document contracts. The former `docs/` tree has been removed after migration; the table below is the exact legacy-to-canonical mapping.

## Contracts

Each concept page uses OKF front matter. Normative pages label status and define exact names; runbooks state goal, inputs, dependencies, and verification; references state purpose and coverage. `index.md` files are reserved and generated by OpenWiki. `_plan.md` is temporary run metadata and is not a durable page.

Source code and tests are authoritative. README and former docs are intent/routing evidence; if they disagree with implementation, document current source behavior and note the gap rather than preserving stale prose.
